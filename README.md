# 挤奶机器人乳头识别仿真与筛牛系统

TypeScript + three.js 的纯浏览器应用：按线性评定数据参数化重建奶牛乳房 → 模拟机械臂末端 ToF 深度/红外相机（含物理可信噪声）→ 在仿真深度帧上做点云分割与乳头尖识别 → 与模型真值比对 → 套杯过程回放、安装位姿全群扫描、三档筛牛报告与胎次/后备牛预测。牛群档案与仿真结果存 IndexedDB，300 头测试牛首次打开自动生成。

## 运行

```bash
npm install
npm run dev        # http://127.0.0.1:5188
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview
npm run selftest   # Node 下跑 300 头核心算法自检（精度/确定性/耗时）
```

## 页面

- **牛群档案**：耳号、胎次、泌乳天数、乳房深度、前后乳头位置、乳头长度、后乳房高度等；搜索/筛选/排序/增删改；点行跳相机仿真。
- **乳房建模**：四乳区饱满度随挤奶前后与泌乳天数变化；四个乳头独立调长短/粗细/朝向；站姿侧倾/前后倾、后肢位置、尾巴摆角；实时 three.js 模型与真值尖坐标。
- **相机仿真**：ToF 模组分辨率/FOV/工作距离/调制频率；机械臂末端位姿（XYZ + 俯仰/偏航）滑杆可调；深度伪彩与红外强度并排；识别四个乳头尖并逐头给 mm 误差，尾巴/后腿误识单独计数；一键做同种子两遍确定性校验。
- **套杯回放**：机械臂从进牛位到四个杯依次套上的 3D 动画，每杯路径、被后腿遮挡采样、重扫次数与事件时间线；可播放/暂停/拖动/变速，可换牛。
- **筛牛报告**：全群 Web Worker 评测 → 能进机器人 / 要盯着 / 只能去挤奶厅三档；安装高度×俯仰成功率热图与最优点；后备牛体型预测头胎乳房下垂；单牛连推三胎看从哪胎起不适合；导出给场长的 HTML 报告与 CSV；点牛跳相机页。
- **设置**：阈值、随机种子、IndexedDB 数据管理、重新生成 300 头、导入/导出 JSON、Worker 内全群精度与确定性自检。

## 仿真核心（`src/core`，不依赖 DOM/three）

- `rng.ts`：种子化 mulberry32 + 字符串哈希，全系统随机性唯一来源，保证同牛同种子逐位复现。
- `primitives.ts`：球/椭球/胶囊/平面的光线求交与线段遮挡。
- `cowModel.ts`：线性评定 → 解析乳房/四乳区/四乳头/后腿/尾巴图元与真值乳头尖。
- `tof.ts`：针孔 ToF 渲染；红外强度 ∝ 反照率·cosθ/距离²；弱回波增大深度噪声；边缘飞点；乳房-后腿凹处多径偏远；沾水湿斑饱和无效。
- `recognize.ts`：XZ 最低包络 + 最大值滤波基准 → 乳头尖种子 → 圆柱迭代生长 → 稳健轴/球冠拟合 → 尖点；形状与置信门剔除腿/尾/退化簇；与真值全局贪心匹配评分。
- `attach.ts` / `pipeline.ts`：视线与杯路径遮挡、重扫、回放时间线、单牛试验。
- `screen.ts`：三档分群、后备牛预测、胎次推移。
- `herd.ts`：300 头确定性测试牛，按比例掺入后乳头交叉、极短乳头、拖地乳房、沾水等缺陷。

## 关键工程约束

- **确定性**：相同 `(牛, 相机配置, 种子)` 产出相同深度数组与识别结果（自检会比对帧哈希与尖点 JSON）。
- **不卡 UI**：全群评测与热图/精度自检都在 `src/workers/batch.worker.ts`，带进度消息，可继续操作界面。
- **所见即所算**：three.js 牛体网格由同一份求交图元生成（`src/three/CowView.ts`）。

> 说明：噪声参数、体型→下垂公式与分档阈值是工程上合理的仿真标定，用于演示筛选逻辑，不构成真实牧场的医学/选型结论。
